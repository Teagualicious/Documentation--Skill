# Developer / Builder Guide Requirements

The developer guide is for engineers, builders, administrators, maintainers, operators, and future owners.

## Required sections

1. Project overview
2. Scope, maturity, source version, and documentation status
3. System context and external boundaries
4. Architecture and component responsibilities
5. Workflow and data flow
6. Setup, installation, import, and configuration
7. Interfaces, actions, data contracts, and public entry points
8. Security, permissions, credentials ownership, and data handling
9. Testing and validation
10. Deployment, environment promotion, release verification, and rollback
11. Monitoring, diagnostics, failure modes, and recovery
12. Maintenance, common changes, technical debt, and known limitations
13. Evidence, assumptions, conflicts, and unresolved questions

## Content rules

- Use exact names only when confirmed.
- Label examples and placeholders.
- Explain why components exist and how they interact, not only what files are present.
- Include failure and recovery behavior for every material workflow.
- Identify administrator-only or destructive actions.
- State what was not analyzed.
- Include the source revision and last verification date.

# Generic Low-Code and No-Code Profile

Use this profile when no more specific platform profile applies.

## Evidence to request or inspect

Prefer, in order:

1. Exported project or workflow package
2. Machine-readable action or configuration definition
3. Run history or logs
4. Diagram or screen-recording transcript
5. Screenshots
6. Existing SOP or user guide
7. User description

## Blueprint fields

Capture:

- Platform and environment
- Project, workflow, app, or automation name
- Trigger
- Inputs and validation
- Ordered actions
- Branches, conditions, loops, and parallel steps
- Data sources and destinations
- Connections, owners, and permissions
- Outputs and notifications
- Success criteria
- Failure, timeout, retry, and duplicate behavior
- Monitoring and support ownership
- Deployment, export/import, versioning, and rollback

## Common risks

- Personal connections used for production
- Environment-specific IDs embedded in actions
- Missing duplicate prevention
- Manual retries that repeat external actions
- Undocumented premium connectors or licenses
- No owner for failed runs
- Screenshots that omit hidden settings or expressions

Keep these as risks or questions unless evidence confirms them.
